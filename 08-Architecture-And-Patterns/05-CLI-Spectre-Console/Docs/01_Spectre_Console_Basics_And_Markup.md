# 01. Основи Spectre.Console: Розмітка, Кольори та Візуальні Панелі

## 1. Чому Spectre.Console замість стандартного `Console.WriteLine`?

Стандартний клас `System.Console` має фундаментальні обмеження:
1. Зміна кольору через `Console.ForegroundColor = ConsoleColor.Red` глобально змінює стан консолі. Якщо забути скинути його через `Console.ResetColor()`, весь наступний вивід буде пошкоджений.
2. Неможливо вивести декілька кольорів в одному рядку без розриву викликів `Console.Write`.
3. Відсутність адаптивності до розміру вікна терміналу, відсутність підтримки багатоколоночних таблиць та складних рамок.

**Spectre.Console** усуває всі ці обмеження завдяки власній декларативній системі розмітки (Markup) та багатій об'єктній моделі візуальних віджетів.

---

## 2. Синтаксис розмітки (Markup Syntax)

Spectre.Console використовує зручний теговий синтаксис, схожий на BBCode:

```csharp
// Вивід стилізованого тексту з комбінацією кольорів та стилів
AnsiConsole.MarkupLine("[bold green]Успіх:[/] Замовлення [underline yellow]#{0}[/] збережено в базі даних!", orderId);

// Екранування спеціальних квадратних дужок:
AnsiConsole.MarkupLine("[[Примітка]]: для виводу дужок використовується подвійне відкриття.");
```

Підтримувані стилі тексту: `bold`, `dim`, `italic`, `underline`, `invert`, `strikethrough`.  
Підтримувані кольори: 16 стандартних кольорів, 256 розширених кольорів та повноцінний RGB TrueColor (наприклад, `[rgb(255,100,50)]`).

---

## 3. Віджети `Panel` та `Rule`: Організація інтерфейсу

Для структуризації екрана використовуються візуальні розділювачі (`Rule`) та блоки (`Panel`):

```csharp
// Горизонтальний стилізований розділювач:
var rule = new Rule("[yellow]Панель Керування[/]");
rule.RuleStyle("grey");
AnsiConsole.Write(rule);

// Інформаційна панель із заокругленою рамкою:
var panel = new Panel(new Markup("[white]Сервер працює в штатному режимі.\nАктивних сесій: [green]142[/][/]"))
{
    Header = new PanelHeader("[blue]Статус Системи[/]"),
    Border = BoxBorder.Rounded,
    Padding = new Padding(2, 1, 2, 1)
};
AnsiConsole.Write(panel);
```

## 4. Порівняння: `System.Console` проти `Spectre.Console`

| Можливість | `System.Console` | `Spectre.Console` |
|:---|:---|:---|
| **Зміна кольору** | Глобальна мутація через `ForegroundColor` | Локальні закриті теги `[red]...[/]` |
| **Таблиці та Сітки** | Лише складний ручний підрахунок символів пробілів | Автоматичні респонсивні таблиці `Table` |
| **Інтерактивні списки** | Потрібно вручну зчитувати `Console.ReadKey` | Готові меню зі стрілочним вибором `SelectionPrompt` |
| **Кросплатформність** | Поведінка кольорів залежить від хоста Windows/Unix | Уніфікований рендеринг через стандарти ANSI |
