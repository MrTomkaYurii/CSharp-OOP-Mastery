# EX_01. Порівняльний аналіз асинхронних патернів (EX_01_async_await)

## Теоретичний огляд

Цей проект надає інтерактивну консольну лабораторію для порівняння синхронного та асинхронного виконання.

### Ключові концепції:
1. **CPU-Bound операції та `Task.Run`:**
   Коли потрібно виконати важкі обчислення (сортування великого масиву, криптографію, стиснення), метод `Task.Run()` переносить обчислення з головного потоку у фоновий потік `ThreadPool`.
2. **I/O-Bound операції та `Task.Delay`:**
   Не потребують окремого фонового потоку на час очікування. Вони використовують асинхронні системні таймери ОС (I/O Completion Ports).
3. **Конкурентний старт завдань:**
   Запуск `PrintNameAsync("Tom")`, `PrintNameAsync("Bob")`, `PrintNameAsync("Sam")` без негайного `await` дозволяє всім трьом операціям тривати одночасно. Загальний час скорочується з 3 секунд до 1 секунди.

## Структура меню програми

- `1) Асинхронні методи async та await`: обгортка синхронного блоку в `Task.Run`.
- `2) Затримка асинхронної операції Task.Delay`: чистий TAP.
- `3) Синхронне виконання`: послідовна затримка (3 сек).
- `4) Асинхронне виконання`: конкурентна затримка (1 сек).
- `5) Лямбда-вираз у Task.Run`: запуск обчислювального циклу на 1,000,000 ітерацій.
