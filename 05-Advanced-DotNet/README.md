# Глава 05: Метапрограмування, Рефлексія та Користувацькі Атрибути у .NET 10

Ця глава присвячена механізмам середовища виконання CLR та метапрограмування: дослідженню метаданих типів під час виконання (`System.Reflection`), динамічній кодогенерації (`Expression Trees`), безпечному доступу без витрат (`[UnsafeAccessor]`), створенню власних атрибутів (`System.Attribute`), серіалізації (`System.Text.Json`, `XmlSerializer`) та побудові власного IoC/DI-контейнера з нуля.
