# Лекція 5: Методи Розширення, Вкладені та Часткові Класи

## 1. Методи Розширення (Extension Methods)

**Методи розширення** дозволяють «додавати» нові методи до існуючих типів (включаючи типи сторонніх бібліотек чи .NET BCL, такі як `string`, `int`, `IEnumerable<T>`) без створення похідних класів чи модифікації вихідного коду:

```csharp
public static class StringExtensions
{
    // Перший параметр з ключовим словом 'this' вказує тип, який розширюється:
    public static bool IsValidEmail(this string input)
    {
        if (string.IsNullOrWhiteSpace(input)) return false;
        return input.Contains('@') && input.Contains('.');
    }
}

// Використання:
string email = "student@univ.edu";
bool valid = email.IsValidEmail(); // Виглядає як екземплярний метод!
```

> [!NOTE]
> Компілятор транслює виклик `email.IsValidEmail()` у статичний виклик `StringExtensions.IsValidEmail(email)`. Саме на методах розширення побудована вся екосистема **LINQ** (`Where`, `Select`, `OrderBy`).

## 2. Вкладені Класи (Nested Classes)

Клас, оголошений всередині іншого класу, називається **вкладеним**:
* Має повний доступ до **всіх приватних членів** зовнішнього класу.
* Може бути оголошений як `private` (і бути повністю невидимим за межами зовнішнього класу).
* Часто використовується для реалізації внутрішніх допоміжних структур: вузлів дерев (`Node`), ітераторів або патернів `Builder`.

---

## 3. Часткові Класи та Методи (`partial`)

Модифікатор `partial` дозволяє розділити оголошення одного класу, структури або інтерфейсу між кількома файлами вихідного коду:
* Під час компіляції всі частини зливаються в єдиний монолітний тип у метаданих IL.
* Незамінний при роботі з **генераторами вихідного коду (Source Generators)** у .NET 10 (наприклад, для `System.Text.Json`, regex та Windows Forms).
