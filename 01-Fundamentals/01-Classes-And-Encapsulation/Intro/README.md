# Intro — з C++ на C# за одну пару

Чотири невеликі консольні проєкти. Кожен запускається окремо (`Program.Main`)
і послідовно друкує пронумеровані розділи — читайте вивід поряд з кодом.

| Проєкт | Про що | Ключові відмінності від C++ |
|---|---|---|
| **01_ConsoleAndTypes** | вивід/ввід у консоль, типи, змінні, рядки, перетворення типів | немає `.h` і forward-декларацій; `Console` замість `<iostream>`; інтерполяція `$"{x}"`; `string` незмінний і `==` порівнює вміст; `bool` строгий; `int.TryParse`; переповнення `checked` |
| **02_ControlFlowAndLoops** | `if`/`switch`, `switch`-вираз, зіставлення зі зразком, усі цикли, індекси `^` і діапазони `..` | умова тільки `bool`; `switch` не «провалюється»; `foreach`; pattern matching і діапазони — без аналога в класичному C++ |
| **03_Methods** | оголошення й перевантаження, необов'язкові/іменовані параметри, `out`/`ref`/`in`, `params`, кортежі, рекурсія, локальні функції, делегати й лямбди | вільних функцій немає — усе в класі; замість вказівників для вихідних параметрів — `out`/`ref`; кілька значень — через кортеж; функція у змінній — `Func`/`Action` |
| **04_CoolStuff_FromCppToCsharp** | LINQ, колекції (`List`/`Dictionary`/`HashSet`), `record`, зіставлення зі зразком, робота з рядками, null-безпека (`?.` `??` `??=`) | те, заради чого варто радіти переходу |

## Як запускати

У Visual Studio: правою кнопкою на проєкті → **Set as Startup Project** → F5.

З консолі:

```bash
dotnet run --project Intro/01_ConsoleAndTypes
```

Рекомендований порядок вивчення: 01 → 02 → 03 → 04.
