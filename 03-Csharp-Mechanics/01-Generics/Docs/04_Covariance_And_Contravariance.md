# Лекція 4: Варіантність в Узагальненнях: Коваріантність (`out`) та Контраваріантність (`in`)

Узагальнені типи за замовчуванням є **інваріантними**. Наприклад, навіть якщо `Dog` успадковує `Animal`, об'єкт `List<Dog>` **НЕ є** `List<Animal>`.

*Чому це заборонено?* Якби це було дозволено, можна було б написати:
```csharp
List<Dog> dogs = new List<Dog>();
List<Animal> animals = dogs; // Уявімо, що це дозволено
animals.Add(new Cat());      // Катастрофа! Кіт опинився у списку собак!
```

---

## 1. Коваріантність (Covariance): ключове слово `out`

**Коваріантність** дозволяє використовувати більш похідний тип замість менш похідного. Дозволена **лише тоді, коли тип є вихідним (Output)**: об'єкти тільки повертаються з методів, але ніколи не передаються всередину:

```csharp
// Інтерфейс коваріантний за типом T (out):
public interface IProducer<out T>
{
    T Produce(); // ✅ Дозволено: T повертається
    // void Consume(T item); // ❌ Помилка: T не може бути вхідним параметром!
}

// Використання:
IProducer<Dog> dogProducer = new DogKennel();
IProducer<Animal> animalProducer = dogProducer; // ✅ Працює завдяки 'out'!
```
Стандартний приклад BCL: **`IEnumerable<out T>`**.

---

## 2. Контраваріантність (Contravariance): ключове слово `in`

**Контраваріантність** дозволяє використовувати менш похідний тип (базовий) там, де очікується більш похідний тип. Дозволена **лише тоді, коли тип є вхідним (Input)**:

```csharp
// Інтерфейс контраваріантний за типом T (in):
public interface IConsumer<in T>
{
    void Consume(T item); // ✅ Дозволено: T передається як аргумент
}

// Використання:
IConsumer<Animal> animalConsumer = new AnimalShelter();
IConsumer<Dog> dogConsumer = animalConsumer; // ✅ Працює завдяки 'in'!
```
Стандартний приклад BCL: **`IComparer<in T>`** та `Action<in T>`.

---

## 3. Зведена шпаргалка варіантності

| Термін | Ключове слово | Позиція типу | Правило збереження відношення | Приклад у .NET |
|:---|:---:|:---:|:---|:---|
| **Інваріантність** | *(немає)* | Вхідні та вихідні | Збіг лише 1-в-1 | `IList<T>`, `Dictionary<TKey, TValue>` |
| **Коваріантність** | **`out`** | Тільки вихідні (return) | `Dog` ➔ `Animal` | `IEnumerable<out T>`, `Func<out TResult>` |
| **Контраваріантність** | **`in`** | Тільки вхідні (parameters) | `Animal` ➔ `Dog` | `IComparer<in T>`, `Action<in T>` |
