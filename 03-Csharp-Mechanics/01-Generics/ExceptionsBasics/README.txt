ExceptionsBasics — класичні винятки: try / catch / finally
============================================================

Консольний проєкт із меню. Кожен пункт — один короткий приклад.
Делегати та лямбди не використовуються.

Запуск:  dotnet run --project ExceptionsBasics

Пункти меню (усе в Demos.cs):
  1. try / catch            виняток — це об'єкт; виконання стрибає з try у catch
  2. Кілька catch           перший підходящий виграє; від конкретного до загального
  3. finally                виконується завжди: без помилки, з помилкою, після return
  4. Розкрутка стека        Level1 -> Level2 -> Level3; виняток летить вгору по викликах
  5. throw; та throw ex;    чому 'throw ex;' стирає справжнє місце помилки
  6. using                  скорочений try / finally для IDisposable (Resource.cs)
  7. Порожній catch         антипатерн: помилка проковтнута, результат хибний
  8. Виняток чи TryParse    виняток — для виняткових ситуацій, а не для звичайної логіки

Помилка компіляції (пункт 2): розкоментуйте  // #define ERR_CATCH_ORDER  на початку
Demos.cs  ->  CS0160 (catch (Exception) перед catch (DivideByZeroException)).

Що читати далі: проєкт ExceptionsCustom (власні класи винятків).
