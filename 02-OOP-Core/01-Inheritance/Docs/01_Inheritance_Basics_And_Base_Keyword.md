# 01. Базове спадкування, ключове слово `base` та конструктори

## 1. Концепція успадкування (Inheritance)

**Успадкування** — це фундаментальний механізм ООП, що дозволяє створити новий клас (похідний / `derived class`) на основі вже існуючого (базового / `base class`). Похідний клас автоматично переймає всі поля, властивості та методи базового класу (окрім конструкторів і фіналізаторів), додаючи до них власні або розширюючи існуючі.

* Відношення між базовим і похідним класом виражається принципом **«IS-A»** («є»): `Dog` **є** `Animal`, `Manager` **є** `Employee`.
* Якщо похідний клас оголошує поле або метод із тим самим іменем, що є в базовому класі, модифікатор **`new`** явно позначає **маскування (приховування)** успадкованого члена.
* Ключове слово **`base`** дозволяє звернутися з похідного класу безпосередньо до прихованого члена базового класу (`base.Field1`) або викликати базовий конструктор (`: base(...)`).

## 2. Порядок виконання конструкторів (`base` та `this`)

При створенні екземпляра похідного класу конструктори викликаються у суворій послідовності: **від вершини ієрархії донизу (від базового до похідного)**:

```mermaid
flowchart TD
    A["1. Виділення пам'яті в купі для ВСІХ полів базового + похідного класу"] --> B["2. Ініціалізатори полів та виклик конструктора базового класу (: base(...))"]
    B --> C["3. Виконання тіла конструктора похідного класу (DerivedClass)"]
```

* **`: base(...)`** — делегує ініціалізацію базової частини об'єкта конкретному конструктору базового класу.
* **`: this(...)`** — делегує роботу іншому перевантаженому конструктору **цього ж класу**, дозволяючи уникнути дублювання коду ініціалізації.
