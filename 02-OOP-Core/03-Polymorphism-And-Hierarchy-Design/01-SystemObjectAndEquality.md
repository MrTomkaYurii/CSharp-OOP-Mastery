# 01. Корінь ієрархії `System.Object` та семантика рівності

У .NET абсолютно кожен тип прямо чи опосередковано походить від **`System.Object`** (псевдонім `object` у C#). Навіть якщо ми пишемо `class MyClass` без двокрапки, компілятор автоматично підставляє `class MyClass : System.Object`.

---

## 1. Контракт методів `System.Object`

| Метод `System.Object` | Вид методу | Поведінка за замовчуванням для класів | Навіщо перевизначати (`override`) |
|:---|:---:|:---|:---|
| **`ToString()`** | `public virtual` | Повертає повне ім'я типу (`Namespace.ClassName`). | Для зручного логування, налагодження та відображення стану об'єкта. |
| **`Equals(object? obj)`** | `public virtual` | Порівнює посилання (адреси в купі). | Коли об'єкти мають порівнюватися за бізнес-ідентифікатором або значенням полів. |
| **`GetHashCode()`** | `public virtual` | Генерує хеш на основі внутрішнього індексу об'єкта в CLR. | **Обов'язково** перевизначається разом із `Equals` для коректної роботи `Dictionary<K,V>` та `HashSet<T>`. |
| **`GetType()`** | `public` (невіртуальний) | Повертає об'єкт метаданих `System.Type`. | Не можна перевизначити — гарантує правдиву інформацію про реальний тип у купі. |
| **`MemberwiseClone()`** | `protected` (невіртуальний) | Створює поверхневу побітову копію полів поточного об'єкта. | Використовується всередині методів клонування класу. |
| **`ReferenceEquals(a, b)`** | `public static` | Перевіряє, чи вказують два посилання на ту саму адресу в купі. | Не можна перевантажити — надійний спосіб перевірити тотожність посилань. |
